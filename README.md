# NTG — Automation Ecosystem

**Practical Python/Bash/Cmd/Other tools for system administrators and developers.**

NTG is a collection of independent, complementary tools designed to automate repetitive tasks, manage systems, process files and work with structured data.

The projects cover different layers of everyday technical work, from system administration to job automation and data processing.

## Explore the ecosystem

### 🖥️ System Administration

**[adminscripts](https://github.com/ntgcorp/adminscripts)**

A collection of administrative scripts and utilities, organized into dedicated folders for practical system administration tasks.

### ⚙️ Job Automation

**[ntJobsApp](https://github.com/ntgcorp/ntJobsApp)** · **[ntJobsOS](https://github.com/ntgcorp/ntJobsOS)**

Tools for automating jobs and operating-system-related tasks. Explore each project for its supported workflows and requirements.

### 📂 File & Data Processing

**[ntj_fact](https://github.com/ntgcorp/ntj_fact)**

Utilities for working with structured data and integrating file operations into automated workflows.

## Design principles

- **Small, focused tools** — each project addresses a specific task.
- **Practical automation** — reduce repetitive manual work.
- **Modularity** — use each tool independently where appropriate.
- **Complementary workflows** — combine tools when a task spans multiple areas.
